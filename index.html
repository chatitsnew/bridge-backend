Score against real roles

Module 3 — Audit

Swap the identity, not the resume

The Ghost Resume panel swaps name, college, and pronouns live and re-scores. The number doesn't move — because the engine was never shown it. Then see the same result proven across 72 statistical comparisons.

How this works — skill extraction and job scoring run on a deterministic rule engine (a ~30-node skills dictionary with weighted adjacency), not a live model call, so results are exactly reproducible in front of judges. The production version of Bridge replaces this layer with an LLM-driven skills inference agent (voice narratives, GitHub code analysis, synthetic skill validation) sitting behind the same module contract shown here — Discovery, Matching, Audit, Pathway — so the interface and the bias-audit logic don't have to change when the inference engine does.
