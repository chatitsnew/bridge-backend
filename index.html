Walkthrough

Four steps, in the order you'll actually use them

Everything below is live in the tool — this is exactly what you'll see after you click "Try it live," in order, top to bottom.

01
Module 1 — Discovery

Paste a resume

Drop in resume text — or pick one of the sample candidates. Bridge extracts explicit skills, then infers adjacent ones the text never states, like React implying JavaScript, HTML, and CSS.

02
Module 2 — Matching

Score against real roles

See a traditional keyword pass/fail and a weighted skills-based score, side by side, across 22 open roles — plus an ATS Translator showing exactly which resume line would fix a missed keyword.

03
Module 3 — Audit

Swap the identity, not the resume

The Ghost Resume panel swaps name, age, college, and pronouns live and re-scores. The number doesn't move — because the engine was never shown it. Then see the same result proven across 264 statistical comparisons.

04
Module 4 — Pathway

Close the gap

For any role a candidate doesn't yet match, get a concrete, curated learning path for the missing skills — a next step, not just a rejection.

Also inside

Built for a recruiter to actually use, not just watch

Role Architect Module 2B

Define a custom role on the spot — title, required and preferred skills, minimum years, degree and gap policy — and score the current candidate against it instantly, through the same engine as every built-in role.

ATS Translator

For every required skill an ATS keyword scanner would miss, get a concrete resume-line suggestion — distinguishing "already on the skills graph but not literally worded" from "no evidence at all."

Verification Toolkit

Every inferred skill comes with a tailored interview question and a concrete way to verify it — so an inference never has to be taken on faith.

Ghost Resume, at scale

The single live identity-swap you can try yourself is backed by a full statistical audit — 12 independently-written candidates, every role, identity swapped — with the full comparison table available to inspect.

How this works — skill extraction and job scoring run on a deterministic rule engine (a ~30-node skills dictionary with weighted adjacency), not a live model call, so every result is exactly reproducible. Upcoming releases extend this layer with an LLM-driven skills inference agent (voice narratives, GitHub code analysis, synthetic skill validation) sitting behind the same module contract shown here — Discovery, Matching, Audit, Pathway — so the interface and the bias-audit logic don't have to change as the inference engine evolves.
